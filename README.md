# 凯侠 × 4062 · 波段手记

移动端优先的日线策略助手。部署地址：<https://shadow5673.github.io/Trading-Position/>。

替换原 Six Apples 仓位计算器，保留原 GitHub Pages 地址与 Git 历史。无需框架、服务器或券商密钥。

## 固定策略

`C-PARTIAL-CD5-v1`：收盘高于 MA20，MA20 高于 5 个交易日前；此前 3 日触及 MA10；收盘突破前日最高。次日开盘跳空在 ±3% 内入场。100 股整数手按现金买入，不加杠杆。

R = 1.5 × 信号日 Wilder ATR14。初始止损 P−R；P+2.5R 先卖约一半（奇数手先多卖一手，只有一手则全卖）。最高收盘达到 P+R 后，下一日起止损为 max(旧止损, P, 最高收盘−2×当前ATR)，只能上调。包括买入日最多 10 个交易日，并保留 28 自然日限制。最后清空仓位的卖出腿亏损后，暂停接下来 5 个交易日，第 6 个交易日方可恢复，仍需新信号。

## 使用

1. 总览切换凯侠285A / 揖斐电4062。新账户默认各1,000万日元，已有凯侠本金与记录不覆盖；设置各自账户本金和记录起始日。已有仓位请填写买入前资金，按实际日期补录。
2. 检查行情是否齐备，核对四项信号；符合时核算次日开盘范围和股数。
3. 券商实际成交后记录成交价格、日期和股数。网页不下单、不自动假设成交。
4. 每个收盘更新日线，核对下一交易日止损和持仓期限。盘中触价在券商执行。
5. 定期导出 JSON 备份；更换设备时导入。

初始 ATR 在买入记录中锁定。分批卖出不重置持仓日数。真实成交若偏离入场条件，可明确勾选记录偏离，不伪装成合规信号。

## 数据

- `data/market.json`：285A.T Yahoo 日线。包含既有回测历史。
- `data/market-4062.json`：4062.T 日线、已核对的拆股除权交易日和比率。两份行情分别更新；数据存储交易日实际价格（不复权）。
- `data/calendar.json`：日本现货交易日历，截至 2027 年底；JPX 官方休市日。
- 页面支持逐日补录或 `date,open,high,low,close,volume` 格式 CSV，成交量为股。只接收完整收盘数据；缺日、重复、错误高低价会拒绝。
- `update-market.yml` 在日本时间工作日 16:20–23:50 每 30 分钟尝试刷新；修改该工作流或 `scripts/update_market.py` 并推送到 main 时也会运行一次以自检。逐只处理：Yahoo 访问失败、无法解释的历史价格变化、未核对的拆股、数据缺失时保留该只旧文件；另一只成功更新仍可发布。已核对的拆股会还原为交易日实际价格，并验证历史一致。若应有的新日线尚未到达，任务报错而非误报成功，旧文件仍保留。GitHub 定时任务可能延迟数小时、被跳过、停用或遇到访问限制，排程不是完成时间保证；页面会以真实日期提示过期，仍可手工补录。
- 自动更新提交后显式请求原 GitHub Pages 分支构建；需要仓库 Actions 的 contents/pages 写权限以及原有 Pages 配置。不会创建新的域名。

## 隐私

本金、真实交易、手工补录仅在本浏览器 `localStorage`（`swingDesk.285A.v1` / `swingDesk.4062.v1`）保存，不上传 GitHub 或任何后台，无统计脚本。不同设备不自动同步。静态页面请求只读取公开资源。JSON 备份包含资金与成交，请自行保管。每只分别导出，备份带股票代码；旧版无股票代码的备份仅允许恢复到凯侠。跨股票备份会拒绝。已有凯侠存储键不变，只有保存该股票操作时才写入。

旧页面的存储键 `positionManagerData` 不读取、不迁移，也不主动删除。

`tests/reference.json` 是模拟回测的固定测试夹具，不是用户真实账户记录。

## 限制

不是券商交易终端；价格触发需要在券商执行。页面给出理论参考价格，实际挂单按券商报价单位核对。跳空与涨跌停可能无法按止损价成交。行情依赖外部源和人工输入，不保证实时。实际账户按记录成交价计算，未自动处理税款、融资费用、分红或外部出入金。增加/提取资金需要先核对账本，不能当作交易盈利。交易日历到期需要更新。

历史回测反复用同一股票样本选择规则，不能证明未来收益或回撤上限。

## 双股票与拆股

两个资金池互不调钱；各自执行同一C规则，盈利复投/亏损扣本，暂停期互不影响。总览权益逐账户相加；如果某只无法加载，则明确标记汇总不完整。行情过期的股票保留旧值并提示日期，禁止生成新的入场建议。

4062 已核对 2025-12-29（1拆2）与 2026-09-29（1拆2）的除权交易日。后者公司法律生效日为10月1日，但股价/交易股数从9月29日按拆股后口径。资料链接随行情元数据保存（JPX公告与公司文件）。

原始成交始终保存当时的价格、股数、信号ATR；渲染时按计划适用交易日换算历史价格、成本、股数、ATR和止盈止损。拆股不会改变现金、权益、持仓起始日或已部分止盈状态。交易记录表仍显示原成交数值。拆股前一天收盘后的计划显示次日换算值并突出提示；卖出录入按所选成交日期核算，不能把计划股数误记为前一日成交。盘中保护订单仍需用户与券商核对。

`npm test` 包含旧凯侠完整回测回归、双账户隔离、旧备份兼容、跨股票拒绝、拆股前后权益/止损/股数、部分卖出和暂停测试。Python离线测试覆盖单只更新失败不阻塞另一只、已核对拆股还原历史、未知拆股失败关闭。

页面可见时每5分钟读取网站已发布日线，切回浏览器也会检查；填写弹窗期间不打断输入。此刷新不是实时行情，仍受后台发布进度限制。
